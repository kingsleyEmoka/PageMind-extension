01

Everything you need,
nothing you don't.

Smart Extraction
Heuristic content scoring identifies the main article body, filtering out navbars, sidebars, ads, and comments before sending anything to AI.
Reading Time
Instantly know how long the original article takes to read — calculated at 200 words/minute alongside a full word count.
Key Insights
Beyond the summary, AI identifies 3–5 actionable or notable insights that are easy to miss on a first skim.
Highlight Mode
Toggle in-page highlighting of key phrases directly on the webpage. One click turns it on; one click removes it cleanly.
Smart Caching
Results are cached per URL for 30 minutes in local storage. Revisit the same page and get instant results — no duplicate API calls.
Secure by Design
Your API key lives only in local storage and is accessed exclusively in the background service worker. It never touches the page context.

03

Up and running
in 60 seconds.

1

Clone the repository

Download or clone from GitHub. No build step — pure vanilla JS.

2

Open Chrome Extensions

Navigate to chrome://extensions/ and enable Developer mode (top right toggle).

3

Load unpacked

Click Load unpacked and select the ai-page-summarizer/ folder.

4

Add your API key

Click the PageMind icon → ⚙ Settings → paste your Anthropic API key. Get one free at console.anthropic.com

5

Summarise anything

Navigate to any article, click the icon, and hit Summarise Page.

04

Clean architecture.
Zero shortcuts.

  USER clicks PageMind icon
       │
       ▼
  popup.js  ──── EXTRACT_CONTENT ────▶  content.js  (page context)
                                              │
                                     heuristic scoring
                                     noise filtering
                                     text extraction
                                              │
       ◀──────────── { title, content, url, wordCount } ─────────────
       │
       ├── check chrome.storage.local for cached result
       │
       ▼
  popup.js  ──── SUMMARISE ───────▶  background.js  (service worker)
                                              │
                                       validate sender ID
                                       load API key from storage
                                              │
                                       POST /v1/messages
                                       api.anthropic.com
                                              │
                                       parse JSON response
                                       cache result by URL
                                              │
       ◀──── { summary, keyInsights, readingTime, highlights } ───────
       │
  render UI
  optionally inject highlights via HIGHLIGHT_PHRASES → content.js
API key never in content scripts
Sender ID validated on every message
textContent used — XSS impossible
host_permissions scoped to Anthropic only
CSP restricts scripts to 'self' only
